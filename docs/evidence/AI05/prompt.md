# AI05 — завершение длинных ответов

Пользователь сообщил об обрыве ответа и попросил исправить его без тестового прогона. В принятом AI04 вызов провайдера ограничивался 600 токенами, флаг завершения игнорировался, длинный ответ свыше 8 000 символов считался ошибкой. Для конкретного прошлого ответа флаг не сохранялся.

Исполнителю cat01 (Sol, low) переданы серверный адаптер, соответствующие тестовые ожидания и таймаут Caddy. Требования TECH-03, TECH-06, SEC-02. При исчерпании бюджета длины автоматически запросить до двух продолжений и собрать одно сообщение с сохранением Markdown. Обычный короткий ответ требует одного вызова. Для ограничений по времени, длине и ошибкам сохранить черновик. История студентов изолирована, адрес провайдера, модель и ключ остаются в серверных настройках.

Приёмка по чтению diff. Тесты, вызовы API, smoke-проверки и браузерные прогоны исключены по указанию пользователя. После приёмки перечитать код в работающем процессе локального сайта и выполнить обычное версионирование.
