# CAT02 — повторные раунды, перестановка и образы

Запрос: «игра не дает сыграть второй раз вылетает сайт. и сделай ее более динамичной, пусть карточки переставляются между собой. сгенерируй три разных картинки кота на фото для разных выбранных характеров».

Основной агент создаёт три imagegen-образа и архитектурные/evidence документы; исполнитель gpt-6.1-sol/low исправляет код, без дальнейшей делегации. Read TASK/AGENTS/ARCHITECTURE27/PLAN16, taste skill. Разрешены cat.py/JS/CSS/portrait templates и целевые tests/evidence, без модели/миграции/зависимостей. Воспроизвести повторную победу до изменения, не выдумывать причину; укрепить жизненный цикл раундов, async guards, очистку timer, retry и переходы. Перестановки каждые2секунды с сохранением идентичности нажатой/фокусированной цели, без движения в calm/reducedmotion/pause. В игре и профиле выбирать новый WebP по сохранённому характеру. Контракты наград/владельца/CSRF сохраняются.

Приёмка:2победы на одной странице +ещё одна после гардероба, timeout/retry, мониторинг pageerror/requestfailed; реальные координаты карточек меняются, фокус/calmpause стабильны;10серверных и browser сценарии,360/1440,3изображения загружаются. Freeze исходников перед независимой проверкой. Не commit/push до accepted.
