# AI06 — учебная роль помощника

Пользователь попросил ограничить тематику через мастер-промпт. Пример постороннего запроса — рецепт блинов. Учебные объяснения, подготовка к экзаменам и помощь с деканатом входят в задачу. При неясной связи с учёбой помощник может уточнить цель. В смешанном запросе отвечает на учебную часть.

Исполнителю cat12_rating, gpt-6.1-sol / low, поручено добавить серверное сообщение с ролью system в начало каждого запроса к модели и сохранить контекст продолжений AI05. Постановка касается apps/accounts/assistant.py, tests/test_assistant.py и отчёта исполнителя. Проверки должны подтвердить порядок сообщений, сохранение прежней истории и совместимость заглушек провайдеров. Интерфейс и конфигурация провайдеров находятся вне объёма. Связанные требования — PRD-01, TECH-03, SEC-02.
