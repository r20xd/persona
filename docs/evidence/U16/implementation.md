# U16 · Реализация исполнителя

Запрос: пары одного дня показываются внутри одной карточки. Требования: CORE-02, PRD-02–04, TECH-06.

Прочитаны TASK, AGENTS, ARCHITECTURE §§7/9/11, PLAN F03, постановка U16, текущая дизайн-система и актуальный taste-skill 2.5.1. Применены согласованная палитра persōna, единая поверхность, ровные края, простые разделители, последовательные заголовки и фокус. Маркетинговые hero/фотографии/анимации не применялись к локальной правке кабинета.

В schedule() добавлен список days из уже отсортированного timeline с явной московской датой timezone.localdate(..., timezone=MOSCOW). Сохранены timeline и действующие выборки/права; группировка не обращается к БД. Шаблон выводит h2 диапазона, h3 дня и h4 занятия. Отмена и перенос имеют разные сплошную/пунктирную отметки и прежние текстовые статусы, история и ссылка переноса сохранены. Поверхность и скругление 18px перенесены с каждой пары на день, строки отделены тонкой линией; мобильные строки складываются внутри карточки. Новые стили группировки ограничены .schedule-list, session/preview не менялись.

Browser fixture добавляет через create_lesson вымышленное второе занятие на фиксированное 4 ноября 2026, 11:00 МСК. Проверки: один контейнер на день, две строки, хронология, отмена и раскрытие истории, распределение недели по дням, переход переноса, длинные заголовки/подпись ссылки и overflow на 360/1440. UPDATE_EVIDENCE=1 сохраняет новые снимки в U16, прежние снимки не меняются.

Фактические проверки исполнителя:

## Исправления после независимого визуального ревью

Основной агент сообщил о 2 passed в Chrome и проверке снимков. По его замечаниям убрана визуальная повторная дата в режиме day: h3 остаётся в accessibility tree и в aria-labelledby карточки, используется scoped sr-only CSS с clip-path (без display:none). В fixture второе занятие использует собственную зачисленную дисциплину «Анализ данных» того же demo-студента, исходная отмена «Иностранного языка» сохранена. Добавлена явная проверка двух разных названий. Ruff check/format и git diff --check повторно прошли. Повтор Chrome и обновление снимков выполняет основной агент.
