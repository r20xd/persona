# U14 — плавные переходы между вкладками

Тип интерфейса — студенческий кабинет. Запрос пользователя — добавить плавные переходы между вкладками. Применяются принципы taste-skill для короткого движения в существующем интерфейсе, без изменений раскладки и навигации. Требования PRD-02, PRD-03, PRD-04, TECH-06, SEC-01.

Исполнитель cat12_rating, Sol / low, добавляет отдельный CSS и подключает его только на полных GET ответах основных вкладок активного студента. Браузерный View Transition показывает только новый контент. Старый снимок и снимок оболочки не отображаются. Cсылки остаются обычными. Уменьшенное движение оставляет обычный переход. Загрузка страницы в браузере без поддержки функции следует обычным правилам навигации.

Приёмка основного агента включает наблюдение настоящего события перехода и анимации на 360 и 1440 px, проверку клавиатуры, навигации назад, обычных форм и reduced motion. Предыдущее решение обновлять приватную страницу при возврате через BFCache не меняется.
