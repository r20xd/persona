# ANN02 · Убрать кнопку прочтения у оператора

Пользователь попросил убрать у оператора кнопку «Отметить прочитанным» в «Уведомлениях». Убрать из HTML кнопки и формы прочтения для событий и объявлений у оператора. У студента оставить действующие кнопки. Область задачи — шаблон `apps/notifications/templates/notifications/feed.html`. Сохранить признаки прочтения, настройки ленты, объявление и переход к событию.
