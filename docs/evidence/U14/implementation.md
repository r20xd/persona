# U14 — переходы вкладок

Тип: существующий software кабинет студента; цель движения — обозначить новое содержимое при обычной навигации. Применены актуальные Taste SKILL 2.5.1 и references/motion.md: короткий ease-out, только opacity/transform, без overshoot, без движения при reduced motion; прежняя палитра/компоненты/кот не менялись. Прочитаны TASK, AGENTS, интерфейсные разделы ARCHITECTURE и Q03/ADR001 о BFCache.

Первый вариант использовал native cross-document View Transitions. Root подтвердил движение в полном Chromium, но регрессионный мобильный тест обнаружил InvalidStateError при переходе к странице без opt-in (logout), а bundled headless shell не показывал переход. По changes requested полностью удалены @view-transition и псевдоэлементы снимков. Финальный вариант использует только entrance нового #main: opacity .8→1 и translateY 5px→0 за 200ms. Fill mode остаётся none: после 200ms на main не остаётся transform/нового containing block. Старых снимков и переходов, которые могут отклоняться, нет; до активации содержимое сразу читаемо.

Небольшой локальный defer JS активирует CSS-класс только при prefers-reduced-motion:no-preference, PerformanceNavigationTiming type=navigate и непустом same-origin referrer с другим pathname из основных вкладок. Список путей берётся из .campus-nav a/.header-profile, дополнен двумя адресами сессии. Direct initial load без referrer, reload/back/forward, query-only смена и источник вне вкладок пропускаются. CSS также ограничен media no-preference. Никакого хранения состояния, перехватов ссылок, истории, форм, фокуса или задержки навигации нет. Существующие обработчики BFCache не менялись.

Base подключает CSS/JS только для active authenticated student, GET и whitelist основных вкладок (home/schedule/session/session-legacy/grades/requests/students/cat/assistant/notifications/profile). Подключение обёрнуто в block workspace_transition_styles; accounts/access_error.html явно переопределяет его пустым блоком. Оператор, login, POST, редакторы, карточка каталога вне whitelist. Глобальные error handlers возвращают JSON и не используют base. Существующий единственный #main каждого включённого шаблона переиспользован. База/сервер/Git не затронуты.

Исполнитель: gpt-6.1-sol / low без субагентов. Фактические проверки: статический просмотр base/включённых шаблонов/error handlers/ADR001; git diff --check — clean. Browser QA, реальные переходы, reduced motion, BFCache и Taste gate выполняет root. Тесты вне scope исполнителя, не запускались. Полная визуальная готовность не заявлена.
