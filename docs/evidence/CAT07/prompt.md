# CAT07 — спрайты и выразительность

Пользователь: «переделай кота в 48x48, добавь больше анимаций и сделай их выразительнее, игрушки сделай 32x32».

Основной агент: архитектура, постановка и независимая приёмка. Исполнитель: существующий cat01, gpt-6.1-sol/low, один writer без субагентов. Обязательный taste-skill прочитан; точная пиксельная графика создаётся кодовым генератором. Требования: PRD-03/04, TECH-03/06, пользовательский CAT07; контракты ARCHITECTURE §30.

Создать scripts/generate_cat_pixel48.py: настоящая новая геометрия48×48 и32×32, не nearest resize32/16. Сохранить трёх характеров, ограниченную палитру, бинарную альфу, старые assets. Семь состояний с переменным количеством кадров: idle6, blink6, jump8, joy8, stretch8, yawn8, surprise6. Приседание/полёт/приземление, лапы, хвост, веки и рот должны делать движения различимыми. Генератор работает из произвольной директории без новых зависимостей.

Подключить новый набор через cat.py, cat_portrait.html, cat.js и cat.css. Убрать предположение о четырёх кадрах; автоматические жесты только в активной игре, действия имеют приоритет. Правильный выбор → jump, неверный → surprise, победа → joy. Пауза/hidden/calm/reduced motion останавливают и сбрасывают кадр; профиль статичен. Подогнать сцену под кота и четыре увеличенные игрушки без перекрытия лица/обрезки и с точными физическими пикселями при DPR1/1.25/2. Сохранить20секунд,12карточек, быстрые перестановки, сохранение и правила наград.

Разрешённые области: новый генератор/static/images/cat-pixel48; cat.py/JS/шаблон/CSS кота; релевантные tests/test_cat_pixels.py, tests/test_cat.py, browsertests; docs/evidence/CAT07/implementation.md и визуальные материалы. Не менять зависимости, модели, миграции, чат, .env, .gitignore, исходные пользовательские картинки. Root отдельно ведёт архитектуру/план/review. Commit/push только после accepted и ограниченного follow-up.

Проверки: независимое декодирование PNG/CRC/сетки/палитры, совпадение генерации с shippedassets, смысловая разница кадров и поз; реальный browser360/1440, все характеры и четыре игрушки, реакции/автопозы, повторные раунды, статичный профиль, reduced/calm/pause/hidden и DPR. PostgreSQL тесты на отдельном временном экземпляре55439. Зафиксировать фактические результаты и ограничения, не объявлять опубликованный сайт проверенным.
