# DEMO28 · реализация

Исполнитель: `gpt-6.1-sol` / low, Codex. Требования: CORE-02, DEMO-01, DATA-01, TECH-03. Изменены только команда продления, регрессии dashboard/demo и этот отчёт. UI и схема не менялись, рабочая локальная БД не изменялась исполнителем.

В `extend_demo_schedule` добавлен опциональный `--through-date YYYY-MM-DD`: закрытый промежуток от `--anchor-date` или текущей московской даты. Добавляются свободные будущие будни и конечная суббота; воскресенья и прочие субботы пропускаются. Две демогруппы получают разные слоты (09:00/11:00), три свои дисциплины чередуются. Отсутствие fixture enrollment приводит к ошибке с откатом общей транзакции. Обычное 48-дневное продление сохранено.

Новые UUID стабильны по демогруппе и исходной дате, найденный ID проверяется на принадлежность одному из трёх своих fixture offering. Команда не восстанавливает отмены/переносы: занятыми считаются также отменённые занятия и старые дни из истории. Перед созданием проверяется активное пересечение с группой, преподавателем или комнатой. Конфликтный слот пропускается. Использованы общий `demo_lock`, atomic transaction и `create_lesson`. Конец семестра растёт только при необходимости для фактически добавляемого занятия.

Проверки на отдельной PostgreSQL 17, порт 52494, БД `test_demo28_worker`; секреты в отчёт не включаются. Первый прогон нашёл ошибку тестовой подготовки: удаление Enrollment запрещено связанными GradeResult; исправлено удалением связанных тестовых результатов перед удалением enrollment. Sandbox запрещал loopback TCP, повтор сделан через штатное разрешение. Проверка ресурсной коллизии исправлена по ревью: конфликт в 11:00 26 ноября ещё будущий при часах 10:00, а слот другой группы 09:00 уже прошёл.

Регрессии подтверждают: шесть добавленных строк на 24/26/28 ноября для двух групп, разные дисциплины, сохранность всех исходных строк и истории отмены, перенос дополнения и идемпотентный повтор, отсутствие сжатия семестра, ошибку обратного диапазона, откат при неполных зачислениях, пропуск прошедшего слота, ресурсной коллизии и неконечной субботы/воскресенья. Ruff check и format проходят. Полный `tests/test_dashboard_demo.py`: 13 passed (предварительный прогон); результат окончательного повторного прогона ниже.
