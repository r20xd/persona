# COPY02 · Приёмка переноса слогана

**Статус** — `accepted`. 21 ноября 2026 года. PRD-03, PRD-04, F01. [Постановка](prompt.md) · [Реализация](implementation.md)

Первая фраза сохраняет написание и помещается на одной строке. После неё стоит явный перенос и «Твоё.». Первая проверка при 1024 px выявила дополнительный перенос при 172 px доступной ширины. После корректировки отступа доступно 176 px, размер шрифта остался 12 px.

Один независимый сценарий Chrome прошёл с обеими ролями на PostgreSQL 17. Координаты текста подтвердили две строки, общий левый край и размещение внутри панели при 851, 1024 и 1440 px. При 360 px проверена нижняя навигация. [Снимок панели из тестового кабинета](sidebar-1440.png)

Проверены diff и `git diff --check`. В локальном кабинете HTML обеих ролей проверен в транзакции только для чтения. После сборки статики и обновления Gunicorn readiness ответил HTTP 200, сервер отдаёт новую версию CSS.
