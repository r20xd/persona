# Независимое измерение сетки

Первый одноразовый root capture завершился AssertionError в проверке групп центров. Функциональные тесты уже прошли; код приложения после source freeze не менялся. Root отдельно вывел публичные CSS-координаты, затем сохранил полные visual-metrics.json для шести состояний.

Причина — округление каждого центра до одной десятичной цифры перед группировкой. На assistant1440 численно одинаковые центры находились по разные стороны границы округления из-за точности transform/getBoundingClientRect. Старый способ давал 5 групп по X/Y, хотя видимая сетка была 4×4. Исправлено только независимое измерение: кластеризация координат с допуском .2 CSS px, затем проверка четырёх центров и равных шагов с допуском .21 px. Все исходные дробные координаты сохранены в JSON; размеры, opacity, 16 элементов и восемь transform проверялись отдельно.

Повторный capture: cat1440 30px, assistant1440 27.1562px, profile1440 20.2656px, cat/profile360 25.8125px, assistant360 9px. Во всех шести состояниях ровно 16 одинаковых размеров, четыре ряда/колонки и равные интервалы; нет overflow/browser errors, foreground/pointer-none/aria-hidden сохранены. Сняты также три характера после сохранения через настоящую форму. Собственные fixtures очищены. Повтор pytest не потребовался: приложение не исправлялось.
