# CAT05 — центр и чёткость кота

Запрос пользователя: «сделай котика ровно посередине и улучши качество котика».

Один исполнитель gpt-6.1-sol/low, read TASK/AGENTS/architecture27/PLAN16/taste skill. Разрешены catCSS/portraittemplate и минимальныйJSтолько при необходимости качества, целевой browsertest и implementationevidence. Без моделей/миграций/зависимостей/новой генерации котов. Исходные листы пользователя не менять.

Результат: кот по центру поX/Y сцены и в игре, и в статичном профиле,3характера360/1440. Чёткая pixel rasterотрисовка без лишнего сглаживания, без заявления о новых деталях сверх источника. Кадровый clip/no labels сохраняется; игрушка отдельно рядом без перекрытия тела. Анимации/20секунд/игра/профиль не меняют поведение.

Проверки по риску: геометрия центров, pixelrendering, screenshotcloseups и keyboard/reducedstaticprofile, отсутствие overflow/обрезки/перекрытия. Freeze перед независимым запуском; не commit/push до accepted, не делегировать дальше.

Уточнение root после измерения исходных кадров: разрешены cat.py только координаты defaultframe и JSatlas для исправления несимметричных полей.
