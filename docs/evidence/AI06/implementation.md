# AI06 — учебный мастер-промпт

Исполнитель gpt-6.1-sol / low, без субагентов. Прочитаны TASK, AGENTS, ARCHITECTURE §29 и PLAN AI. По задаче root в серверном адаптере добавлена фиксированная русская SYSTEM_INSTRUCTION первым сообщением role=system перед ограниченным контекстом; эта же инструкция остаётся первой при каждом продолжении AI05. Она задаёт учебный круг тем, уточнение неоднозначной учебной цели, ответ только на учебную часть смешанного запроса, отказ от постороннего содержания (включая бытовой рецепт блинов), устойчивость к смене роли/правил и честное отсутствие автоматического доступа к данным кабинета. По ревью root убрано обязательное русскоязычие, разрешены изучение языков/язык запроса, роль привязана к persōna.

История и исходные сообщения не изменяются; системный текст добавляется только в wire payload адаптера и не сохраняется в сессии/не выводится шаблоном. Словарных фильтров, дополнительных API-вызовов и изменений UI/инфраструктуры нет. Мастер-промпт задаёт поведение модели, но stub-проверки не доказывают фактическое соблюдение ограничений внешней моделью.

Проверки: финальный `TEST_DB_PORT=55439 TEST_DB_USER=deanery TEST_DB_NAME=test_ai06_agent .venv/bin/pytest tests/test_assistant.py -q --tb=short` — 31 passed (3.32s), изолированная PostgreSQL17 и только mock transport. Проверены оба token-параметра wire payload и продолжения, сохранность исходного контекста/истории, отсутствие system в сессии/HTML. Предыдущий прогон до расширения параметризации — 30 passed. Ruff и git diff --check — clean. Живой провайдер/сервер, .env и git записи не затронуты. Независимая приёмка остаётся root.
