# Начальные замечания Q04/U03

Основной агент проверил источники CSS/templates до реализации. Эти наблюдения требуют проверки computed styles и поведения в браузере; полный аудит или сертификация этим документом не заявляются.

| Область | Наблюдение | Проверяемый результат |
| --- | --- | --- |
| Active login input | В preview.css cursor:not-allowed и foreground#6d7b6d на background#edf0ea; accounts override пока отсутствует | Активный input выглядит доступным для ввода, контраст текста не ниже проектного4.5:1; disabled preview сохраняет свою семантику |
| Основная палитра | Расчёт относительной яркости sRGB: muted#5c6b62 на#f4f6f3=5.17, white на#17634b=7.18, nav#e1eae5 на#172b25=12.14; статусы6.4–7.1 | Сохранить палитру; исправлять конкретные недостатки, не менять весь дизайн |
| Focus | Общий selector явно включает a/summary/input, но не button/select/textarea | Видимый keyboard focus на всех основных controls, проверка реального фокуса/достижимости |
| Skip link | Skip link и desktop nav имеют z-index20, nav позже вDOM | Focused skip link виден поверх панели, кликабелен/активируется Enter и ведёт к контенту |
| Validation | Login ручные inputs без явных error associations; request.as_p уже даёт field aria, summary focus отсутствует | Error summary с фокусом, понятные labels/связи, текст сохраняется там, где безопасно |

Active input контраст рассчитан формулой относительной яркости с линейным преобразованием sRGB: **3.8801:1**. Это расчёт цветов из исходника, не измерение всей страницы. Placeholder#65735f на том же фоне=4.3763:1, если placeholder применяется. Focus outline#b78032 на белом=3.4162:1; этот показатель не трактуется как контраст обычного текста.

WebKit runtime на host отсутствует; согласованный Playwright Docker server описан в prompt.md. Любое заявление о Firefox/WebKit/zoom должно ссылаться на фактический запуск, а не установленный бинарник или device scale factor. Реальный телефон остаётся пользовательской проверкой.
