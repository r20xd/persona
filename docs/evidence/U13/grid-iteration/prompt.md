## Владение и результат

Разрешены ТОЛЬКО `static/css/workspace.css`, `apps/accounts/templates/accounts/companion_marks.html`, `docs/evidence/U13/implementation.md`. Root пишет docs/QA/review. Прочие CSS, шаблоны, renderer/JS, assets, модели, зависимости read-only.

Заменить шесть разрозненных марок на 16 одинаковых маленьких span в общем aria-hidden контейнере. В CSS контейнер absolute inset0/z0/clip/pointer-none, display:grid, template-columns/rows repeat(4,minmax(0,1fr)), place-items:center, padding6%, border-box. Все ячейки одинаковы, без случайных координат или разных размеров. Span position:static, width:clamp(9px,36%,30px) (36% от ширины ячейки = примерно9% портрета), aspect-ratio1, единая opacity .12, тот же local smallPNG. У помощника прежний коэффициент .78 можно сохранить (итог .094). Восемь спокойных наклонов циклом, например −18/12/−8/20/8/−14/16/−10deg. Удалить прежние left/top/width/opacity nth-child стили; новые nth-child задают только rotate. Сам контейнер и персонаж не поворачиваются.

Сетка покрывает всю область портрета равномерно. Силуэт и игрушки остаются поверх: центральные буквы естественно закрываются изображением, не создавать большой пустой круг/маску или хаотичное кольцо по краям. Знаки значительно тише и меньше персонажа; без нового изображения, JS, текста, Tabstop, внешних ресурсов или дополнительной загрузки PNG.
