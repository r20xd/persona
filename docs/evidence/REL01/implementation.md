Требования: CORE-01, PRD-05, SEC-01, TECH-03. Постановка: [prompt.md](prompt.md). Код делегирован основным агентом исполнителю; инструменты: Codex, shell/Python для редактирования, Ruff, Django check, pytest. ## Реализация

- `ENABLE_STUDENT_DIRECTORY=False` в общей конфигурации. Только `config.settings.local` читает `DEANERY_LOCAL_STUDENT_DIRECTORY=1`; production и test сохраняют отключение, даже если этот env задан.
- Общий серверный guard в начале обоих directory views выдаёт обычный Http404 до получения профиля и вызовов каталога. Декораторы входа, GET и no-store сохраняются. Собственный `/profile/` и редактор не изменены.
- Отдельный context processor передаёт только boolean настройки; пункт «Студенты» условный. Нет новых зависимостей, схемы или миграций.
- Прежние серверные и браузерные сценарии каталога явно включают демонстрацию. Изолированный browser fixture по умолчанию передаёт env=0, opt-in задаётся indirect параметром. Проверка CAT renderer на directory routes явно включает флаг. Ожидаемое число пунктов стандартной навигации изменено с 8 на 7.
- Добавлены проверки закрытия каталога для трёх студентов (одногруппники и разные группы), чужих/собственных/несуществующих ID, отсутствия ФИО/группы/persōna, неизменной доступности собственного профиля/редактора; selectors каталога заменены падающими заглушками. Browser сценарий закрытия и навигации предусмотрен на 360/1440.
