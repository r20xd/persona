# Просмотр U04

В настроенном локальном окружении остановить свой старый Gunicorn через Ctrl+C, затем:

```bash
uv run python manage.py collectstatic --noinput
DJANGO_SETTINGS_MODULE=config.settings.local uv run gunicorn config.wsgi:application --bind 127.0.0.1:8000 --threads 4
```

Открыть http://127.0.0.1:8000/login/ с ранее созданными student.one/student.two/operator.demo и собственными заданными паролями. Пользовательские env/БД/пароли не заменять. Для начального запуска PostgreSQL и подготовки окружения использовать README.

- Новая сине-серая палитра действует на входе, главной и разделах. Фиксированная навигация на телефоне содержит полное название «Успеваемость».
- Успеваемость показывает оценки/зачёты; Расписание содержит День, Неделя и Сессия. Старый /session/ работает, новые ссылки ведут на /schedule/session/.
- В заявках выбрать другой статус: список меняется сразу. В уведомлениях менять тип и галочку непрочитанных: условия комбинируются, страницы сбрасываются. Проверить «Назад». При отключённом JS используется ручная кнопка.
- Внизу страницы одна компактная отметка конкурсного концепта/неофициального сервиса. Повторные большие подписи убраны; исходные персональные сведения остаются только вымышленными.
