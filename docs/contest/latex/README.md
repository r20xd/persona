# persōna · Описание процесса создания

Исходник конкурсного отчёта находится в [persona-process.tex](persona-process.tex). Все иллюстрации хранятся в `figures/` рядом с ним.

## Сборка

Распакуйте комплект и выполните команду в папке с `persona-process.tex`.

```bash
tectonic persona-process.tex
```

Подойдёт также XeLaTeX. Для закладок выполните два прогона.

```bash
xelatex -halt-on-error persona-process.tex
xelatex -halt-on-error persona-process.tex
```

Для сборки используются Arial и Georgia, при их отсутствии предусмотрены DejaVu Sans и DejaVu Serif. Нужны установленные на компьютере шрифты с кириллицей. Пакеты указаны в преамбуле файла. Комплект собирается отдельно от приложения.
