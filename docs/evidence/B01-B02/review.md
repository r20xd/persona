# B01/B02/F02 — независимое ревью

Статус: accepted для профилей, базовых учебных справочников, операторских областей доступа, входа/выхода и начальных реальных экранов. Это не приёмка всего конкурсного ядра.

Основной агент gpt-6.1-sol/high прочитал модели, сервисы/выборки, формы/обработчики, миграции, provisioning, cleanup, настройки Axes, тесты и шаблоны. Исполнитель gpt-6.1-sol/low исправил замечания: явный backend force_login при нескольких backends, валидация уже существующих bootstrap-аккаунтов без молчаливой замены, rolling expiration Axes, читаемое разбиение HTML. Ошибка временных отметок cooldown fixture обнаружена реальным PostgreSQL-прогоном и исправлена согласованно.

## Независимые проверки родителя

- uv sync --locked, Ruff lint/format, Django check: exit 0.
- 31 foundation/preview/public-login тест без БД: passed.
- Полный `DB_PORT=55432 TEST_DB_PORT=55432 PLAYWRIGHT_BROWSERS_PATH=/tmp/deanery-browsers .venv/bin/pytest --browser-channel chromium`: **46 passed**, 8 секунд.
- `DB_PORT=55432 .venv/bin/python manage.py makemigrations --check --dry-run`: No changes detected, без предупреждения недоступной истории.
- Реальный PostgreSQL17.11 запущен отдельным временным контейнером через установленный Windows Docker CLI. Linux socket остаётся недоступен; системные права не менялись. Только disposable service на loopback55432 использовал trust без пароля; это не production-настройка. Сервис содержит исключительно вымышленные тестовые данные.

Полный suite подтвердил: профили разных студентов и одной группы не смешиваются, прямой адрес чужого профиля отсутствует, внешние next отклоняются, CSRF на входе/выходе, POST-only logout, деактивация/истечение сессии, собственный профиль, role routing, ограничения course/scope, реальное Axes lockout/rolling cooldown с защитой от подмены XFF, идемпотентный bootstrap без изменения пароля и отказ при несовместимом аккаунте. Axes не отключался.

Предупреждения: нет staticfiles до collectstatic в отдельных тестовых настройках; dependency fixture pytest-playwright предупреждает о pytest10, текущий lock ограничен pytest9. Они не подменяют успешные проверки. Реальные стили проверяются отдельным browser QA после collectstatic.
