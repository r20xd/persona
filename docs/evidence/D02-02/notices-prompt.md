# D02-02-N — лицензии Go-компонентов и обязательные notices

Независимая от основного code executor задача. Исполнитель `gpt-6.1-sol / low`, `fork_turns=none`, без субагентов. Читать AGENTS/TASK LIC-01, docs/licenses.md, D02-02 prompt, текущие audit/SBOM JSON. Root явно разрешил параллельную работу: основной исполнитель меняет Dockerfiles/Caddy/audit/TLS runner; здесь области записи не пересекаются.

Факт аудита: Caddy image не содержит notices; Go-модули в machine-readable Trivy inventory не имеют license metadata. Нужен проверяемый bundle исходных license/notice текстов, не весь vendor/source tree. Версии production обновляются на Caddy2.11.9/Go из фактического AFTER inventory, PostgreSQL17.11-trixie (gosu тоже Go), Python3.13.14-slim-trixie. Финальный module inventory передаст root/основной исполнитель; baseline применять только для разработки collector, не выдавать за итоговый набор.

## Результат

1. Узкий воспроизводимый `scripts/collect_image_notices.py`: читает локальные безопасные Trivy JSON outputs по точным image reports, извлекает Go module name/version и Go stdlib, получает соответствующие source archives через официальные Go proxy/sumdb или точные upstream release/tag URLs. Никаких пользовательских URL/credentials, Git token, .env/SSH, Docker socket/контейнеров. Внешним сервисам передаются только публичные module paths/versions.
2. Проверять Go module h1 по pinned go.sum / checksum database: стандартный zip dirhash SHA256/base64, учитывать Go uppercase escaping и pseudo-version/+incompatible. Если полноценная h1 проверка конкретного архива не удалась — не выдавать SHA256 просто скачанного файла за upstream identity proof; показать missing/unverified. Expected checksum/источник+archive SHA256 и license file SHA256 сохранить. Для main Caddy version с отсутствующим self module record использовать публичный sumdb/pinned release, для stdlib официальный точный Go tag `go<version>` LICENSE/PATENTS/AUTHORS по необходимости. Добавить canonical GNU GPLv3 text из gnu.org для Psycopg LGPLv3 combined notices (wrapper LGPL уже в dist-info), не изменять тексты.
3. Из архивов сохранить только применимые LICENSE*/COPYING*/NOTICE*/COPYRIGHT*/PATENTS/AUTHORS тексты (включая вложенные third-party notices), без исходников/executables. Не extractall: безопасные относительные имена, без traversal/symlink, ограничение download/decompressed license size, детерминированный hash-directory для module@version. Никаких запусков fetched code. Тексты неизменные; все byte hashes/URLs/module version в JSON manifest.
4. Output `docs/third-party/runtime-notices/` + manifest. Собрать фактические Caddy2.11.9 и gosu/native Go module sets из AFTER reports; unique modules сохраняются один раз на версию. Перечислить unresolved modules/unknown licenses, лицензии без текста не объявлять разрешёнными по одному названию. Root проверяет оригиналы/условия и пишет docs/licenses.md; collector не заменяет юридическую оценку.
5. Unit tests в `tests/test_image_notices.py` только опасные ошибки: h1/неверный hash, traversal/архивные ограничения, deterministic names; не строить общий fetch framework. Выполнить на public sources с реальным inventory, затем передать root manifest/непокрытые модули и writer freeze. Dockerfile/context COPY bundle меняет основной исполнитель после разрешения root.
