# CAT12 — версионирование

Принятый CAT12 сохранён коммитом `архивная-версия` и отправлен в `origin/main`. После push живой `git ls-remote origin refs/heads/main` подтвердил тот же SHA. В коммит включены ровно 20 файлов согласованного allowlist; `.gitignore` и посторонние файлы не включались. Проверены staged diff, `git diff --cached --check`, ветка `main`, remote `origin`, активный `исторический Git hook` и фактический обязательный trailer соавторства. Проверки и границы приёмки описаны в [review.md](review.md). Это подтверждение исходников, публичный релиз не выполнялся.
