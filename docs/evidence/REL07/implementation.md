# REL07 · Реализация мобильной навигации

Этап закрывает навигационную часть REV-08 и связан с PRD-02–04 и TECH-06. Исполнитель работал в Codex с моделью `gpt-6.1-sol` и усилием `low`, использовал shell и Python для правок, Ruff и pytest-playwright с Chromium для проверок. Перед работой прочитаны AGENTS, TASK, ARCHITECTURE §11, постановка REL07 и design-taste-frontend.

## Изменения

- До 850 px «Главная», «Расписание», «Учёба», «Заявки» и «Уведомления» занимают пять равных ячеек одного ряда. Нижний отступ и область прокрутки рассчитаны на новую высоту панели с учётом safe-area.
- Боковая панель и меню «Ещё» используют общий шаблон `_extra_navigation.html`. CSS исключает скрытую раскладку из порядка фокуса. Каталог зависит от локального флага, текущая страница получает `aria-current`.
- Локальный скрипт закрывает меню по Escape с возвратом фокуса, при щелчке снаружи и при переходе к широкой раскладке. Нативный `details` позволяет раскрыть меню и перейти по ссылкам без JavaScript.
- Существующий `MutationObserver` отслеживает атрибут `open`. Код прогулок использует его, чтобы скрывать кота при открытии меню.
- Мобильная сетка оператора использует отдельный класс роли и две ячейки для очереди и уведомлений.

## Проверки и исправления

Исполнитель запускал установленный Chrome с временными базами `ui_site` в PostgreSQL 17.11 на порту 55439. Первый запуск Chrome в sandbox завершился SIGABRT. Повтор выполнен через штатную эскалацию.

Первый полный запуск четырёх профильных модулей дал **27 passed, 2 failed** за 301,66 с. Проверки каталога, игры, чата и оператора прошли. Два падения относились к переполнению на 320 px и к тестовому клику по заголовку за открытым меню. В следующей версии размещение на 320 px исправлено, а тест кликает по видимой части заголовка.

Тест иерархии теперь проверяет видимую подпись, поскольку ссылка на успеваемость содержит две подписи для разных ширин. После независимого визуального ревью на 360 px увеличена полезная ширина ячеек, а у «Уведомлений» уменьшен интервал между буквами при размере 11 px. Меню выровнено по правому полю шапки. Тест измеряет, помещается ли подпись в одну строку внутри цели.

Итоговый повтор `tests/test_design_browser.py --browser chromium --browser-channel chrome` дал **7 passed** за 68,33 с. Проверены 360, 390, 768 и 1440 px, клавиатурный фокус, размещение на 320 px и 720 × 500, доступность кнопки отправки заявки над панелью, закрытие меню при внешнем клике и переходе к широкой раскладке. Помощник и кот открылись в контексте с полностью выключенным JavaScript. У оператора проверены две цели. Ruff и `git diff --check` прошли. В pytest сохраняется предупреждение `PytestRemovedIn10Warning` от фикстуры Playwright.
