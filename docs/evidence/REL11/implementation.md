# REL11 · Отчёт исполнителя

Реализованы REV-13 / TECH-06 / Q06 и исключение исторических материалов из статической поставки в границах задания. Из Git-дерева `архивная-версия` выбраны 230 графических файлов; 12 актуальных остались по прежним адресам, 218 перенесены из `static/` в `artwork/` с тем же suffix. Перед каждым переносом содержимое сверено побайтно с `git show архивная-версия:<путь>`. Перенос выполнен файловыми операциями, без изменения Git index. Исторические отчёты, корневые референсы и рабочий `staticfiles/` не менялись.

`build_cat_art.py` читает три мастера CAT08 из `artwork/`. Генератор 32 px пишет в `artwork/images/cat-pixel32`, генератор 48 px сохраняет четыре текущие игрушки в `static/images/cat-pixel48`, а три статичных кота и 150 кадров — в `artwork/images/cat-pixel48`. Существующие выходы contact-sheet/preview в исторических evidence не изменены. Генераторы при проверке запускались только во временных каталогах.

По дополнительному поручению основного в `config/settings/preview.py` установлен `STATIC_ROOT = None`: preview обслуживает исходную статику через finders и не включает старые собранные файлы. Local/production не менялись.

Все 436 обычных/хешированных архивных URL получают 404 через WhiteNoise, 24 текущих URL получают 200, 12 хешированных файлов побайтно совпадают с исходными. Реальные значения preview settings используются для проверки source finders: архивные URL 404, 12 текущих обычных URL 200. Старая собранная копия сохранена только во временном каталоге теста.
- Ruff по трём скриптам, двум тестовым модулям и preview settings: **All checks passed**.
- `git diff --check`: успешно.

## Builder и ограничение

Запущен `scripts/build_cat_art.py --check --browser-channel chrome` с изолированными TEST_DB параметрами, без чтения `.env`. Первый запуск в sandbox остановился на запрете loopback bind; повтор через штатную эскалацию запустил временный HTTP-сервер и Chrome. Проверки трёх котов и всех 150 raw/native кадров прошли (код дошёл до проверки малого знака), но итоговый `--check` завершился `AssertionError` на RGBA-сравнении `static/icons/persona-mark-small.png`. Оба файла знака оставлены неизменными; перегенерация не выполнялась. Причина различия Chrome/platform ещё не подтверждена, полный builder check не заявляется успешным.

Инструменты: Python/pathlib и Git read-only для инвентаризации/сверки, редактура Python, pytest/Django/WhiteNoise для регрессии, Ruff, Playwright/Chrome для builder. Новых библиотек, изображений или ручных пользовательских этапов не добавлено. Commit/push и независимая приёмка остаются основному.
