# P03 — объём первой версии

Для обязательного ядра предусмотрена справка об обучении. Назначение выбирается из нейтрального списка, необязательное пояснение ограничено 1000 символами. Данные демонстрации вымышлены. [Требования конкурса](../../README.md#требования-конкурса)

| Внутреннее состояние | Текст интерфейса | Кто меняет |
| --- | --- | --- |
| submitted | Отправлена | Сервер при создании |
| in_progress | В работе | Оператор разрешённой группы |
| ready | Готова | Оператор, только из «В работе» |
| rejected | Отклонена | Оператор, только из «В работе», с причиной |
| cancelled | Отменена | Владелец, только из «Отправлена» |

Терминальные состояния не открываются заново. «Готова» означает подготовку демонстрационной справки; настоящая выдача документа и электронная подпись отсутствуют. Лимиты и проверки повторов заданы архитектурой.

Результаты coursework — баллы с указанным максимумом, экзамены — пять/четыре/три/два, зачёты — зачтено/не зачтено. Неопубликованный результат не виден. Отсутствие результата — «Пока нет оценки»; просроченный срок без опубликованного результата не объявляется доказательством несданной работы.

Первая версия не содержит редактирования профиля/пароля посетителем, загрузки файлов, учебных интеграций, внешних уведомлений и кабинета полноценного администратора. Оператор получает только очередь и разрешённые переходы заявок. Два демоаккаунта могут использовать несколько экспертов; состояние внутри одного аккаунта общее.

Визуальная оценка V1 проверяет стиль и компоновку, а V2 — полный путь перед первым публичным релизом. Технические задачи между этими точками выполняются автономно.
