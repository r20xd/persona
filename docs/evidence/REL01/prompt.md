# REL01 · Изоляция профилей в конкурсной сборке

- Требования CORE-01, PRD-05, SEC-01, TECH-03. Источник — TASK.md, §2–5 AGENTS.md. Аудит REV-01 подтвердил, что PERS04 открывает чужие ФИО, учебные поля и данные «Моя persōna». Основание для следующего блока — «продолжай» после аудита.
- Решение архитектора. Сохранить прежний PERS04 как явно включаемую локальную демонстрацию. Общая конфигурация выключена по умолчанию; production не включает её переменной окружения. Для намеренного локального просмотра разрешить `DEANERY_LOCAL_STUDENT_DIRECTORY=1` только в `config.settings.local`. Прямые GET листинга и карточки при отключении возвращают обычный 404 одним серверным условием до выборок каталога. В отключённом режиме скрыть ссылку в общей навигации. `/profile/` и редактор остаются доступными собственнику. Данные и схема остаются прежними.
- Разрешённые файлы: `config/settings/base.py`, `config/settings/local.py`, `apps/accounts/views.py`, `apps/accounts/context_processors.py`, `apps/accounts/templates/accounts/navigation.html`, `tests/test_student_directory.py`, `tests/test_student_directory_browser.py`, `tests/test_cat_cameo.py`, `tests/test_design_browser.py`, `tests/ui_qa.py`, `tests/test_foundation.py`, `docs/evidence/REL01/implementation.md`. Основной агент ведёт архитектуру, README, приёмку, STATE и Git. Новые файлы вне списка и зависимости согласовать сначала.
- Проверки. Серверно проверить закрытие прямых маршрутов, отсутствие полей чужого профиля, доступность своего профиля для обоих студентов, старую политику локального каталога при явном включении и невозможность включить его из production. Во включённом режиме сохраняются действующие тесты каталога. Проверить отсутствие пункта при стандартном запуске и геометрию навигации на 360/1440. Визуальное изменение — условное отображение одной действующей ссылки, палитра и подсистема движения сохраняются.
