# AI04 — оформление ответов помощника

Тип страницы — существующий кабинет студента. Пользователь прислал план подготовки к экзамену, в котором видны исходные символы Markdown, и попросил выделить ответ цветом. Требования PRD-02, PRD-03, PRD-04, TECH-03, TECH-06, SEC-02, LIC-01.

Исполнитель cat01 (Sol, low) отвечает за серверный вывод Markdown только в сообщениях помощника, контрастное оформление в палитре persōna и тест разметки на маршруте чата. Исходный текст остаётся в сессии и в контексте модели. В HTML разрешена форматирующая разметка, которую создаёт рендерер. Заголовки ответа продолжают иерархию страницы. Сторонние изображения не подгружаются. Исполнитель использует taste-skill и локальные зависимости с проверенной лицензией.

Основной агент проверяет diff, изолированные тесты и реальный диалог с учебным ответом от локальной заглушки в Chromium при ширине 360 и 1440 px. После приёмки обновляет локальный сайт.
