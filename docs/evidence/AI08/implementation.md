# AI08 — анимация портрета помощника

Исполнитель gpt-6.1-sol / low, без субагентов. Прочитаны TASK, AGENTS, ARCHITECTURE §29/§33+, PLAN AI, актуальные Taste SKILL 2.5.1 и motion.md. Существующий software кабинет сохраняет палитру и компоненты. Цель движения — спокойные жесты персонажа; CSS cycle 3.8s, pause, reduced motion, отсутствие движения контейнера соответствуют применённым принципам Taste. ImageGen и QA изображений выполняет root.

assistant.html содержит прежний доступный статичный img, декоративный слой atlas и отдельную кнопку pause/play 44×44 в правом нижнем прозрачном углу avatar (bottom/right 8px, z-index:2), без роста текстовой карточки. Логотипы и их слои сохранены. Отдельный локальный JS декодирует square atlas images/persona-assistant-motion.png только при no-preference; до успешного decode, при ошибке, без JS, reduced motion остаётся старый PNG. Ручная пауза и скрытый документ используют animation-play-state:paused, сохраняя текущую позу и фазу; resume продолжает ту же фазу. Pause/play имеет явное accessibility-имя, native keyboard и видимый focus.

CSS использует единственный image sheet 2×2 и дискретные background-position: покой (верх слева), моргание (верх справа), покой, книга вверх (низ слева), покой, книга вниз/ушки (низ справа), покой. Квадрат слоя позиционируется по ширине/центру object-fit:contain fallback, включая высокий узкий mobile avatar. Для регистрации нового atlas добавлены scale(1.1) и смещение +6% высоты: translateY(-44%) объединяет исходное центрирование -50% и коррекцию +6%. Transform origin center; фон меняется внутри неподвижного слоя. Визуальный clip/центровку проверяет root. Таймеров, requestAnimationFrame и обработки каждого кадра в JS нет. Логика чата, .env, провайдер, БД, сервер и Git не изменялись.

Фактические проверки исполнителя: статическое чтение diff и git diff --check — clean. Размеры исходного fallback img исправлены на фактические 512×512. Root добавил PNG 1254×1254; browser 360/1440, реальные позы/загрузка/пауза/reduced/hidden и Taste gate — независимая приёмка root. Готовность визуального результата до этих проверок не заявлена.

По browser-ревью root кнопка перенесена из текста в нижний правый угол avatar; существующие focus/aria/hover сохранены. Статический diff-check после переноса — clean.
