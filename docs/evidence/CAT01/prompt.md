Внешность взять из cat.jpeg, дизайн выполнить через taste skill.

Исполнитель gpt-6.1-sol/low, отдельный контекст, один writer. Прочитать TASK.md/AGENTS.md, архитектуру§20/27, PLAN§16, workflow/task/review templates, taste skill и обязательные references.
