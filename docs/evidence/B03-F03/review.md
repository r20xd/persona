## Исправления по ревью

- FK на справочник дополнены историческими текстовыми снимками.
- Проверка времени семестра явно использует Москву, а не случайную активную timezone.
- Маркер старого дня сохраняется и при переносе внутри выбранной недели.
- Первая запись истории использует INSERT: новый объект с уже существующим PK не перезаписывает прошлое.
- Добавлен синхронный старт двух независимых соединений в concurrency-тесте.
- После просмотра PNG исправлен наблюдаемый дефект: исторический понедельник больше не идёт после среды/пятницы; общая timeline упорядочена по отображаемому времени.

Просмотрены финальные schedule-week-360.png и schedule-day-1440.png. На узком экране карточки и фильтры читаются, старые/актуальные интервалы различимы; хронология соответствует датам. Исполнитель также проверил CSS200 и computed style после collectstatic, миграцию с сохранением существующих профилей/паролей.
