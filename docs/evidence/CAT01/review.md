# CAT01 — независимое ревью

**accepted локально.** Пользователь поручил отдельную мини-игру и кота в собственном профиле, внешний вид из cat.jpeg, оформление через taste skill.

Root прочитал модель/миграцию, cat.py, JS, шаблоны и изменение навигации. Активный студент получает только собственный cat state через own_profile; нет owner из клиента. Настройки проверяет форма внутри транзакции с блокировкой профиля; GET не создаёт записи. Три POST защищены CSRF, ответы no-store. Сервер выдаёт случайный план и токен попытки, проверяет набор и замену, минимум2секунды/срок2часа, повтор того же результата не добавляет награду. Это игра без стоимости наград и рейтинга, полноценный античит не заявляется.

Визуально просмотрены cat360/1440 и profile360: исходный кот узнаваем, шарфик отображается, поля и подписи читаемы, новая мобильная навигация4×2. Игра имеет таймер45секунд, pause/visibility pause, спокойный режим/reduced motion, native buttons с клавиатурой и понятные сетевые ошибки. Награды доступны последовательно; любимый предмет/реплика зависят от характера.

## Независимые проверки

После freeze финального исправления: `tests/test_cat.py tests/test_cat_browser.py tests/test_persona.py tests/test_student_directory.py tests/test_design_browser.py` на временной PostgreSQL17/Chromium — **40 passed, 1 warning, 55.64s**. Проверены настройка/повторный вход,4награды, replay/новыйtoken, locked accessory, неверные/мгновенные/истёкшие результаты, роль/CSRF/чужая запись, XSS escape, аддитивная миграция и сохранение прежних профилей; live360/1440 игра клавиатурой, смена желания, pause/reducedmotion, timeout, visibility, сетевойretry, выбранный шарфик в профиле после reload; общий design360/390/768/1440 и narrow reflow. Предупреждение pytest о прежней fixture не связано с функцией. Ruff всего репозитория и git diff --check прошли.

Первый независимый запуск:37passed/3failed. Найден реальный bug: ссылка на гардероб меняла только hash, оставляя старые закрытые option. Исправлен переход с новым запросом; отдельно исправлено ожидание стабилизации заведомо движущейся цели в browser test — проверка теперь кликает по её текущим координатам, затем использует спокойный режим. Финальный запуск выше проходит без ослабления серверных проверок.

## Локальный запуск и ограничения

Применена только новая accounts.0004_studentcat, статики обновлены, Gunicorn перезагружен. Попытка предварительного dumpdata не завершилась из-за отсутствующей новой таблицы в старой схеме; команда миграции продолжилась. После аддитивной миграции полный dumpdata сохранён в закрытом игнорируемом backups/cat01-after-additive-migration.json. Это не называется успешным backup перед миграцией. Сохранность существующих данных отдельно проверена migration tests. Публичного релиза нет. Детали применения taste и фактические diagnostics — implementation.md.

Taste gate исполнителя проверял исходный Django-шаблон без рендеринга и вернул FAIL44/WARN11: такой вход не является визуальной проверкой приложения (unresolved static404/неотрендеренные шаблоны). Raw сохранён; успешный gate или performance scan не заявляются. Независимая приёмка опирается на живой браузер и тесты выше. Это ограничение выполнения процесса skill, а не скрытая успешная проверка.
