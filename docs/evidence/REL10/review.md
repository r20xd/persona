## Фактический состав

Сопоставлены шаблоны, CSS, код конфигурации трёх котов и четыре игрушки из серверных вариантов. В новом временном каталоге `collectstatic` с `config.settings.build` собрал 254 файла. Из них 230 — графические файлы проекта. Для каждого хешированная копия побайтно совпала с исходником. Все 12 графических файлов, на которые ссылаются страницы, присутствуют в манифесте. Встроенные SVG-элементы шаблонов идут вместе с HTML. Манифест не содержит файлов шрифтов, HTMX и ресурсов Django Admin.

## Права и происхождение

- Текущие изображения робота и трёх котов прослеживаются по журналам AI01, AI08, CAT08 и CAT09. Четыре текущие игрушки прослеживаются до исходника собственного генератора. Происхождение и места применения указаны в реестре.
- Оба PNG текущего знака сохраняют силуэт из `persona.jpeg`. SHA-256 большого PNG — `5b3b52f28841219d7f7a2d0e30667efd85adfe0c51a093f032af525bdfba86a3`, малого — `3d9cb98c24f44db7e2579a04f0f57bffca8582e2105bba06ad914a7e6d1598b3`. В материалах U07 есть запрос на замену знака и описание обработки. Автор исходника и разрешение на публичное использование и распространение производных в репозитории не зафиксированы. Компактная версия получена из того же рисунка. [U07](../U07/imagegen.md)
- Старые фотографии и листы из CAT01, CAT02, CAT04 и CAT05 также ведут к пользовательским входам. Эти файлы попадают в статику независимо от навигации. Их нужно исключить из поставки с учётом зависимых инструментов и тестов по REV-13. Права на материалы в передаваемых исходниках проверяются по составу выбранного архива или репозитория.
- Опубликованные условия OpenAI сверены по разделам о входах и выходах. Они описывают права в отношениях с пользователем и требование получить нужные разрешения на входы. Для текущего знака сохраняется необходимость подтвердить право на референс или согласовать независимо созданный знак. ## Зависимости и границы

В `uv.lock` 30 сторонних Python-пакетов, 28 установленных версий в локальной macOS `.venv` совпали с lock. `colorama` и `tzdata` имеют условие Windows. Linux-граф без dev содержит 14 пакетов. Файлы MIT `LICENSE` и `LICENSE.markdown-it` из metadata `markdown-it-py 4.3.0` совпали с сохранёнными notices. Файл `LICENSE` из `mdurl 0.1.2` также совпал, включая уведомление авторов Node.js. В Dockerfile установленные дистрибутивы копируются целиком. Сверка этих файлов внутри целевого образа относится к сборке выбранного релиза.

Аудит использовал Git, поиск по локальным исходникам, Django, Python metadata и официальные условия OpenAI. Прошли `test_collectstatic_settings_need_no_database_or_secrets`, `uv lock --check --offline`, проверка относительных ссылок в обновлённом реестре и `git diff --check`. Рабочий каталог собранной статики и данные кабинета не менялись. Результат подтверждает инвентаризацию исходного дерева и поведение офлайн-сборки.
