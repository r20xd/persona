# CLEAN02 · Сводная документация в README

По запросу пользователя перенести в README сведения из четырёх корневых документов, необходимые для запуска, понимания архитектуры, работы команды и сдачи. Удалить отдельные `AGENTS.md`, `STATE.md`, `TASK.md` и `ARCHITECTURE.md`. Оригинал задания должен остаться доступен дословно в истории Git. Связанные требования — TECH-03–05, SEC-01–02, SUB-01–04.

Проверить актуальные ссылки и пересобрать PDF после обновления указателя источников. Код приложения, конфигурация и условия конкурса остаются в прежних версиях.
