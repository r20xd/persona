# CLEAN01 · Очистка дерева репозитория

Пользователь попросил удалить старые спрайты, `PLAN.md` и другие файлы, которые не участвуют в работе проекта и сдаче. База — `архивная-версия`. Связанные требования — TECH-03, TECH-06, LIC-01, SUB-04.

Исполнитель `gpt-6.1-sol / low` отвечает за устаревшие файлы `artwork/`, генераторы 32/48 px и связанные тесты. Дополнительные поручения охватывают старый CSS аккаунтов и шаблон заглушки оператора после проверки ссылок. Мастер-портреты экспортёра, действующие изображения и проверки текущих игрушек остаются. Основной агент отвечает за документацию, удаление промежуточных машинных выгрузок и независимую проверку. Исходники PDF, скриншоты этапов, постановки, приёмка и лицензии входят в объём сохранения.
