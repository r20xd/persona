По сравнению с U11 появились две группированные проверки tilt на новых DOM span (прежние псевдоэлементы checker не проверял). Они точно описывают запрошенный пользователем поворот и сознательно сохранены. Общие container-edges остались открытыми, один selector в группировке изменился; геометрия/контейнеры не правились.

Kind software, прежние палитра/текст/типографика и мотив persōna. Шесть фонов используют один уже существующий 10KB PNG. Новых фотографий, предположений, контактов, эффектов или анимированных циклов нет. Perf заново не измерялся: один прежний ассет из cache, только шесть пустых span и class-only CSS.

Gate проверяет статичный обезличенный Django snapshot; POST/сохранение проверены отдельно настоящими четырьмя Chromium сценариями. Actual Taste shoot и live screenshots также просмотрены. Предыдущие ограничения общей раскладки не закрыты новым декором.
