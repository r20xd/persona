# U14 — принято

Первоначальная реализация через нативные снимки страниц работала в полном Chromium. На мобильной ширине один существующий тест входа и расписания поймал InvalidStateError при выходе на страницу без подключённого эффекта. Эту реализацию заменили анимацией нового содержимого. Она срабатывает по URL предыдущей вкладки и типу обычной навигации. История, скрипты безопасности и формы остаются в существующем потоке.

В Chromium 156 главный блок действительно запустил анимацию длительностью 0,2 с при касании на 360 px и при нажатии Enter на 1440 px. На боковом меню свойство animation-name оставалось none. После завершения основной блок вернулся к transform: none. При reduced motion, Back и перезагрузке движения не было. На страницах входа, формы новой заявки и кабинета оператора файлы перехода не подключались. Горизонтальная прокрутка и ошибки JS в целевом сценарии отсутствовали. Снимки интерфейса после перехода сделаны на вымышленных данных.

Независимый прогон tests/test_session_security.py, tests/test_session_security_browser.py и tests/test_schedule_browser.py на PostgreSQL 17 после исправления дал 18 passed за 59,46 с и одно прежнее предупреждение pytest. Синтаксис JavaScript и git diff --check прошли. Физический телефон отдельно не использовался.

В локальной среде collectstatic установил два новых файла. Gunicorn заменил воркеры. Readiness вернул ok, хешированные файлы совпали с исходниками. Временная PostgreSQL остановлена.

Taste gate на статическом снимке расписания вернул OPEN 29 / 26 WARN. Отчёт относится к существующей раскладке, навигации, состоянию пустого расписания и гуляющему коту. В статическом снимке нет пользовательского перехода, поэтому его работа подтверждена отдельно по событию animationstart на живой странице. Полный вывод сохранён в taste.txt.
