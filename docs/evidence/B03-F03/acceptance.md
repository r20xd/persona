# Проверяемые контракты расписания

Это план проверок, не заявление о выполнении.

| Ситуация | Ожидаемое поведение |
| --- | --- |
| Гость /schedule/ | Переход на вход, без данных |
| Студент группы A без Enrollment курса A | Занятия этого курса не доступны только по совпадению группы |
| Студент B или оператор | Нельзя получить занятия студента A через фильтры/ID |
| День / неделя | Выбор по локальной Москве, понедельник — начало недели, конец диапазона исключающий |
| Неверные дата, view и граничный overflow | Понятный400, не500 и не неограниченная выборка |
| Перенос между неделями | Стабильный UUID, текущая карточка на новой неделе, отметка на старой, видны обе даты |
| Несколько переносов | Одна актуальная запись, история сохраняется, нет активных дублей |
| Отмена | Карточка и причина остаются, не выдаётся за предстоящее активное занятие |
| Параллельное/устаревшее изменение | Один переход по версии, конфликт не перетирает чужую работу |
| Ошибка внутри транзакции | Нет обновлённого занятия без связанной истории |
| Повтор demo provisioning | Нет дублей и изменений ранее созданных записей или паролей |
| Экран360/1440 | Читаемость, навигация/даты работают, нет горизонтального переполнения |

Занятия и история выбираются по разрешённым Enrollment **до** чтения объектов. UUID не считается средством авторизации. История сохраняет старые значения помещения/преподавателя как снимок, чтобы изменение справочника не искажало смысл переноса.
