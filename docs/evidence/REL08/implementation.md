# REL08 · Реализация карточки кота под формой

Этап относится к PRD-02–04, TECH-06 и REV-08. Исходный коммит — `архивная-версия`.

Инструменты: Codex / gpt-6.1-sol (исполнитель), Python для точечных правок файлов, Playwright + самостоятельный Chrome для браузерных проверок, pytest/PostgreSQL 17.11 для серверной регрессии, Ruff и Git diff. Постановка — `prompt.md`; прочитаны AGENTS, TASK, ARCHITECTURE §11/32, PLAN CAT12, REV-08 и актуальный design-taste-frontend по пути с `taste-skill/taste-skill/2.5.1` (короткий путь каталога отсутствует). Применены существующая палитра, равные края карточки, доступные цели и сохранение согласованного интерфейса. Новые ресурсы/зависимости не добавлялись.

Шаблон помощника подключает кота после формы и примечания внутри чата. Переопределение общего блока оставляет на странице один экземпляр кота, вопроса и рейтинга. До 850 px кот движется по собственной полосе, а карточка раскрывается под ним на ширину содержимого чата. При скрытии полоса освобождает место. На широком экране и других страницах используется плавающий режим. При смене ширины фокус остаётся на том же элементе. Для плавающей карточки новая вертикальная координата вычисляется от нижней границы видимой области.

Исполнитель проверял код на временной PostgreSQL по адресу `127.0.0.1:55439`. Серверные тесты использовали базу `test_rel08_worker`, а браузерная фикстура создавала отдельные временные базы.

Первый запуск Chrome завершился SIGABRT и пятью ошибками подготовки тестов. После разрешённой эскалации прошли пять адаптивных сценариев. Замечание основного агента выявило недостаточную высоту карточки после расширения окна. После исправления тест проверяет достижимость звезды и кнопки скрытия в новой раскладке. Проверка меню теперь учитывает сохранённый срок следующего появления кота.
