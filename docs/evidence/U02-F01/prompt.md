# U02/F01/A03 — постановка

Пользователь: «продолжай». Основной агент выбрал следующий блок по STATE: первая визуальная версия и CI, не зависящие от доступности локального Docker.

Исполнитель foundation, gpt-6.1-sol / medium, получает follow-up в прежнем ограниченном контексте. Требуется Django preview главной и входа с fiction-данными, local/test-only маршруты, адаптивная оболочка 360/1440, доступность и честные пояснения ещё не реализованных функций. Цвета/структура описаны в docs/ux/design-system.md. Публичная публикация не разрешена.

Разрешены apps/core preview, templates/static, config routes/settings, scripts/preview.sh, README, dev dependency pytest-playwright и реальный uv.lock, тесты, GitHub CI и implementation/screenshots в этом каталоге. STATE/PLAN/ARCH/AGENTS/design-system и review принадлежат родителю. Commit/push только после приёмки.

Приёмка: реальные HTML/браузерные проверки, отсутствие горизонтального переполнения на 360 px, рабочие ссылки, запрет preview в production, отсутствие вводимого пароля/ложной отправки, screenshot desktop/mobile. CI с изолированным PostgreSQL и строгим lock. Недоступные проверки фиксировать отдельно. Sites применён только как local-only preview workflow; выбранная Python-архитектура сохраняется.

## Изменение по ходу этапа

Пользователь поручил перейти на основной gpt-6.1-sol/high и исполнителей gpt-6.1-sol/low, добавляя каждому будущему коммиту `атрибуция команды`. Предыдущий исполнитель medium оставил частично написанный preview. После смены сессии живых прежних субагентов не было; новый `preview_low` запущен явно с fork_turns=none, model=gpt-6.1-sol, reasoning_effort=low и продолжил фактическое дерево. Историческая часть этой постановки не переписывается как будто предыдущий запуск тоже был low.

Launcher и commit-msg hook независимо проверены родителем (stub и три случая идемпотентного trailer), сохранены отдельно в архивная-версия с требуемым соавтором; push и SHA remote подтверждены. Hook включён только в текущем clone. Реализация UI/CI продолжается отдельным этапом.
