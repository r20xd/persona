# REPORT01 · Конкурсный отчёт в LaTeX

Пользователь попросил подготовить описание процесса создания в формате LaTeX со скриншотами. Для SUB-04 и TECH-05 в документе должны быть проблема и разделы, опрос при наличии, инструменты с назначением, промпты и диалоги, скриншоты этапов, объяснение входа и защиты, ручной вклад.

Основания для текста — TASK, проектный журнал, подтверждённый черновик REL12, архивные снимки этапов и поставленные пользователем задачи. Архивные кадры датировать. Новый браузерный сценарий заявки проводить на отдельной PostgreSQL с вымышленными аккаунтами. Вручную зафиксированные действия брать из диалогов и материалов команды. Учётные данные, пути на устройствах участников и содержимое конфигурации в описание не переносить. Отчёт делать без отправки организаторам.

Результат — PDF для жюри и исходник LaTeX с иллюстрациями. Проверить сборку, каждую страницу и комплект исходников.
