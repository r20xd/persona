# Просмотр редизайна U05

В уже настроенном локальном окружении остановите старый сервер через Ctrl+C, соберите статику и запустите приложение:

```bash
uv run python manage.py collectstatic --noinput
DJANGO_SETTINGS_MODULE=config.settings.local uv run gunicorn config.wsgi:application --bind 127.0.0.1:8000 --threads 4
```

Откройте http://127.0.0.1:8000/login/ и используйте свои ранее заданные демонстрационные доступы student.one/student.two/operator.demo. Для первого запуска БД и подготовки окружения смотрите README. Пересоздавать свои данные или менять пароли ради редизайна не требуется: схема БД не менялась.

1. Сравните вход и главную на компьютере и при ширине360px. Ближайшее событие, его дата и переход в расписание должны быть видны сразу.
2. Просмотрите расписание дня/недели/сессии и успеваемость. Проверьте читаемость времени, изменений занятий, итогов и текущих работ.
3. Подайте заявку, откройте её статус, смените фильтр списка. Войдите оператором и обработайте заявку; вернитесь студентом, чтобы увидеть результат.
4. В уведомлениях проверьте автоматический выбор типа и непрочитанных. На главной просмотрите радар и сводку; подтверждение сводки выполняется отдельной кнопкой.
5. Проверьте навигацию пальцем и Tab, видимость фокуса и отсутствие перекрытия контента нижней панелью.

Скриншоты `before/` и `after/` сняты с настоящего локального приложения на вымышленных данных. `early/` — промежуточный вариант для внутреннего ревью. Это локальный результат; публикация и контрольная точка V2 полного пути студента/оператора пока не подтверждены.
