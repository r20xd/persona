# REL06 · Независимая приёмка восстановления после ошибок

**Статус** — `accepted` для REV-09, PRD-02, PRD-04, PRD-05, SEC-01 и TECH-06. [Постановка](prompt.md) · [Реализация](implementation.md)

Ревью кода подтвердило сохранение HTTP-кодов 400, 403, 404 и 500, `no-store` и согласование JSON по `Accept`. Запрос и исключение не передаются шаблону, обработчик не обращается к профилю или сессии. При отсутствии манифеста страница и ссылка на `/` остаются доступными. Ссылка использует GET. Статусы владения, проверки входа и специализированные ответы CSRF и форм сохранены.

Независимый прогон `test_foundation.py`, `test_schedule.py`, `test_grades.py`, `test_notifications.py`, `test_requests.py`, `test_access_matrix.py` и `test_student_directory.py` дал **295 passed** на PostgreSQL 17.11. В Chromium реально открыты HTML 400 и 404 на 360 и 1440 px. Проверены безопасный возврат гостя на вход и студента в кабинет, управление клавиатурой, отсутствие отражения параметров и горизонтального переполнения, загрузка локального CSS с хешем и цели высотой от 44 px. Проверка применяла критерии design-taste-frontend к соседству текста и действия. [Ошибка 400 на 360 px](error-400-360.png) · [Ошибка 404 на 1440 px](error-404-1440.png)

Docker Hub не отдал закреплённый образ. Независимая проверка использовала официальный бинарник Caddy 2.11.9 для arm64 с проверенной SHA-256 `d075afc620376679a77b453399bf7ada264cab3280b2833e4ed1372abc0c1c13`. `caddy validate` подтвердил конфигурацию, отметив существующие замечания о форматировании и `header_up`. На loopback запущен фактический Caddyfile с недоступным upstream. Обычный адрес вернул 502 с русским HTML и ссылкой `/`, оба точных health-пути вернули 502 с `{"status":"unavailable"}`. Во всех ответах был `no-store`. Это локальная проверка обработчиков ошибки. [Релиз Caddy](https://github.com/caddyserver/caddy/releases/tag/v2.11.9) · [Контракт handle_errors](https://caddyserver.com/docs/caddyfile/directives/handle_errors)

Ruff check, Ruff format, Django check и `git diff --check` прошли. Локальный Gunicorn перечитал код. Готовность базы вернула 200, тестовый отсутствующий адрес — HTML 404. Публичное размещение остаётся отдельным этапом после V2.
