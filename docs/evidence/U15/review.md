# U15 · Приёмка личных дедлайнов и главной

**Статус** — `accepted`. 20 ноября 2026 года. Требования PRD-04, CORE-05, SEC-01, TECH-03 и TECH-06. [Постановка](prompt.md) · [Дедлайны](implementation-deadlines.md) · [Главная](implementation-home.md) · [Меню кота](../CAT13/review.md)

- Проверен полный серверный набор на отдельной PostgreSQL 17.11: **487 passed**, 90 браузерных тестов исключены из этого запуска. Матрица доступа проверяет новый маршрут вместо удалённой карточки учебного срока. Ruff, проверка синтаксиса JavaScript и `git diff --check` прошли.
- В выбранном наборе **27 сценариев Chrome получили успешный результат**. В первом запуске прошли 23. Два сценария уведомлений повторно прошли после перевода теста на действующую навигацию, два сценария радара — после уточнения локаторов существующего переноса и новой отмены. После правки формы повторно прошли оба сценария личных дедлайнов. Существующая фикстура Playwright выдала предупреждение о совместимости с будущим pytest.
- Независимый сценарий в Chrome на 360 × 844 и 1440 × 900 подтвердил создание дедлайна, ошибку пустой даты, переход из уведомления к своей записи, отметку выполнения, сохранение при повторном входе и возврат задачи в работу. Второй студент получил 404 по той же ссылке и увидел собственный список. Шесть вкладок помещаются в мобильную панель, все видимые элементы навигации имеют высоту не менее 44 px. [360 px](deadlines-360.png) · [1440 px](deadlines-1440.png)
- В браузере проверены отсутствие пяти запрошенных секций и надписи «ВАШИ ПРИОРИТЕТЫ», равные границы радара и карточки ближайшего события, действия из главной и отсутствие горизонтальной прокрутки. [360 px](home-360.png) · [1440 px](home-1440.png)
- Отдельный тест перехода `notifications 0002 → 0003` сохранил все прежние строки учебных сроков, уведомлений и заявок. Архивные уведомления исключены из выдачи. Прежний URL учебного срока закрыт, напоминания о личных сроках создаются только для владельца активной задачи.
- Обновлена локальная база, пересобраны статические файлы и перезагружен Gunicorn. `/login/` и `/health/ready/` ответили 200, новый `/deadlines/` перенаправил гостя на вход с 302. [Локальная вкладка](http://127.0.0.1:8000/deadlines/)
