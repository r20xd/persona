# REQ01 · Принять заявку одной кнопкой

Пользователь попросил убрать выпадающий список при принятии заявки в работу и оставить кнопку. На карточке новой заявки оператор видит одну кнопку «Принять в работу». Она отправляет существующий переход `in_progress` с CSRF и текущей версией. В статусе «В работе» используется действующая форма завершения или отказа. CORE-04, PRD-02, PRD-04, TECH-03.

Разрешены `apps/requests/templates/requests/detail.html`, браузерные тесты заявок, уведомлений, главной, UI доступности и автофильтров, а также `docs/evidence/REQ01/implementation.md`. Перед UI прочитать актуальный Taste Skill. Проверить переход и повтор со старой версией в изолированной PostgreSQL. Локальную пользовательскую тестовую заявку использовать для проверки отображения без изменения статуса.
