# K01 — как посмотреть новые возможности

На уже подготовленном локальном окружении из README остановить свой сервер, применить additive миграцию и запустить его снова. Пользовательские пароли/БД не заменять, seed повторно для этого не нужен:

```bash
uv run python manage.py migrate
DJANGO_SETTINGS_MODULE=config.settings.local uv run gunicorn config.wsgi:application --bind 127.0.0.1:8000 --threads 4
```

Команды выполнять в терминале с прежними настроенными переменными окружения. Адрес http://127.0.0.1:8000/login/, логины student.one/student.two/operator.demo, пароли — ранее заданные самостоятельно. Это локальный просмотр, не публикация сайта.

1. Войти как student.one и открыть главную. «Требует внимания» собирает актуальные подтверждённые события со ссылками. Первый обычный вход начинает отслеживание сводки; исторические записи не выдаются за новые. Если сессия осталась от прежней версии, доступна кнопка «Начать отслеживание».
2. Создать новую заявку. В отдельном приватном окне войти как operator.demo, открыть её, взять в работу, затем отметить готовой.
3. В студенческом окне открыть главную. В «Пока вас не было» появятся новые переходы статуса. Обновление страницы их не стирает. Отметить показанное просмотренным, обновить страницу и войти повторно: отметки сохранятся.
4. Готовая заявка останется в радаре после просмотра сводки. Это актуальный статус, а не непрочитанное сообщение. Прочтение в разделе уведомлений учитывается независимо.
5. Войти как student.two: сводка и радар относятся к этому аккаунту. Повторить просмотр на ширине360px и desktop.

Публикации оценок и изменения занятий учитываются из существующих серверных источников. Ограниченный операторский кабинет редактирует только заявки. Полные примеры новых оценки/отмены/статуса получены реальным браузером на отдельной вымышленной QA-базе: attention-digest-360.png/1440.png и viewport варианты. Эти картинки не являются снимками пользовательской dev-базы.

K01 не заменяет контрольную точку V2 и проверку публичного сайта; hosting/домен/стоимость ещё не выбраны. Текущая палитра сохранена.
