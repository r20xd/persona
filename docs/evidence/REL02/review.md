# REL02 · Независимое ревью

**Статус** — `accepted` по локальной приёмке TECH-03, TECH-05 и A03. [Постановка](prompt.md) · [Отчёт исполнителя](implementation.md)

Изменения четырёх файлов, которые указал `ruff format --check .`, подтверждены сравнением AST с предыдущей версией. Операции миграций и проверяемое поведение совпадают. Проверка однородности пикселей временно скрывает декоративный слой во время `Page.screenshot`. У размерности, DPR, выборки из реального снимка и условий однородности остались исходные значения. Видимость декора проверяется до и после снимка.

Независимый целевой прогон подтвердил все три значения DPR в составе **23 passed** на PostgreSQL 17.11 и Chromium. `ruff check .`, `ruff format --check .`, `uv lock --check --offline`, Django check, `makemigrations --check --dry-run` и `git diff --check` прошли. Новый файл миграции не требуется. Фактический запуск Actions для релизного SHA проверяется отдельно.

После прерывания предыдущего процесса финальный набор повторён на последней редакции обоих этапов. `pytest --collect-only` обнаружил 531 тест. Серверная часть `-m 'not browser'` дала 451 прошедший тест, четыре непересекающиеся группы `-m browser` — 20, 23, 20 и 17. Итого **531 passed**, без падений. Каждая браузерная группа повторила существующее предупреждение pytest о `base_url`. Использовались отдельная временная PostgreSQL 17.11 и Chromium Playwright 156.0.8078.4. Рабочая БД не использовалась.
