# REL11 · Архив вне выдаваемой статики

**Статус** — `accepted` для REV-13 и TECH-06. Проверка относится к выдаваемой статике кандидата и конфигурации его сборки. Вопросы о текущем знаке и составе исходников для жюри продолжают отслеживаться по LIC-01. [Постановка](prompt.md) · [Отчёт исполнителя](implementation.md) · [Инвентаризация до переноса](../REL10/review.md)

По Git-блобам `архивная-версия` проверены все 218 перемещённых файлов и 12 текущих файлов. Содержимое совпало. Исходники экспортёра CAT08 и исторические PNG доступны в `artwork/`. Генераторы 32 и 48 px воспроизводят прежние данные, четыре активные игрушки по-прежнему генерируются в `static/images/cat-pixel48/`.

| Проверка | Результат |
| --- | --- |
| Офлайн-сборка в пустой каталог | 36 записей в манифесте вместо 254 в REL10. 436 старых адресов дали 404, все текущие обычные и хешированные URL дали 200. |
| Обновление копии прежнего `STATIC_ROOT` с `--clear` | 436 прежних обычных и хешированных URL дали 404. Все 36 оставшихся записей манифеста совпали с прежними значениями. |
| Режим preview с существующей старой локальной папкой | 436 старых URL дали 404, а 12 текущих обычных URL дали 200 через finders. |

| Docker через `FROM scratch` и `COPY .` | Первая проба после переноса выявила попадание всей папки `docs/` в контекст. Отсутствуют `artwork/`, `docs/evidence/`, `.env` и `staticfiles/`. Размер итогового серверного образа проверяется при сборке релиза. |

Независимо прошли **64 серверных и 12 браузерных тестов** на PostgreSQL 17.11 и Chrome. Проверены исходная и собранная статика, профиль, три варианта кота, Canvas, четыре игрушки, мини-игра и помощник. Ruff, Django check для preview и `git diff --check` прошли. Сохранилось прежнее предупреждение Playwright о pytest.

`build_cat_art.py --check --browser-channel chrome` прошёл сравнительные проверки трёх котов и 150 кадров до проверки миниатюры знака. На этом шаге получен `AssertionError` при сравнении RGBA. Основной агент воспроизвёл сбой на чистом дереве `архивная-версия` с тем же Chrome. Оба действующих файла знака совпадают с Git-блобами исходной версии.

## Передача статики в Chrome

Каждый маршрут открыт с новым браузерным контекстом на 360 и 1440 px. Для закрытых страниц переносилась тестовая сессия в памяти. Сумма `transferSize` ресурсов `/static/` одинакова на обеих проверенных ширинах. Метрика включает заголовки переданных ресурсов.

| Страница | Байты `transferSize` |
| --- | ---: |
| Вход | 976 389 |
| Главная студента | 33 692 |
| Кот | 42 006 |
| Помощник | 955 466 |

Среди запросов не было архивных файлов или ошибок загрузки статики. В игре подтвердилось появление Canvas, у помощника загрузился атлас. Результаты относятся к локальному контуру и измерению текущей сборки.

В локальном кабинете сгенерированный `staticfiles/` заменён свежей сборкой с резервной копией во временном каталоге. Gunicorn перечитал манифест. Вход и оба health-маршрута дали 200. На порту 8000 отдельно подтверждены 404 для трёх старых файлов в обычном и хешированном виде и 200 для актуального знака, кота и атласа помощника с побайтной сверкой. V2 остаётся на согласовании.
