Исполнитель: `gpt-6.1-sol`, `low`, один writer, без собственных субагентов.
Постановка: [prompt.md](prompt.md). Требования: CORE-01–05, PRD-01–05,

Статус: реализация завершена, независимая приёмка и версионирование родителем
ещё не выполнены. Коммитов/push/публикации исполнитель не выполнял.

## Реализация

- `seed_demo` последовательно вызывает существующие provisioners в одной
  транзакции; добавляет две заявки со стабильными UUID submission keys через
  реальные сервисы. Первый студент получает отправленную заявку, второй —
  готовую с настоящей историей переходов. Переходы выполняются только при
  первом создании фикстуры. Блокировка профиля перед проверкой ключа защищает
  это условие также от гонки с обычной отправкой формы.
- Общая PostgreSQL transaction advisory lock сериализует все демокоманды.
  Существующие пароли/роли/scope, заявки, результаты, прочтение, сроки и
  изменения занятий не сбрасываются. Проверки идентичности отклоняют
  несовместимые справочники, аудитории объявлений и владение фикстурами.
  Пароли принимает прежний private env/getpass bootstrap, без argv/вывода.
- `Term.starts_on` хранит исходный Monday−7, поэтому отдельная metadata и
  миграция не понадобились. Начальное расписание покрывает предыдущую неделю
  и восемь недель от исходного понедельника: 54 занятия двух студентов,
  переносы и отмены. Повтор без даты использует сохранённый период.
  `extend_demo_schedule` добавляет отсутствующие занятия со starts_at>now
  по тем же стабильным UUID, монотонно расширяя только конец семестра.
  Существующие события и история не перемещаются. Календарь ОС не меняется.
- Старый `demo-coursework` сохранён; для каждого студента добавлен отдельный
  upcoming coursework/deadline без опубликованного результата. Это позволяет
  главной показывать реальный срок, не выдавая оценённую работу за несданную.
- Новый `apps/dashboard` не имеет моделей: сводка использует серверные scoped
  selectors/ORM, ближайшее занятие или событие сессии, последние версии
  изменений на неделю, собственные сроки и заявки, текущий семестр и
  опубликованные итоги, свои события и объявления/unread. Отменённые события
  исключены из ближайшего; прошедший срок не считается доказанной несдачей.
  При отсутствии текущего семестра явно подписан последний прошедший период;
  только будущие семестры не превращаются в текущий учебный итог.
- `/` теперь сводная главная студента; `/profile/` остаётся собственным
  профилем. Оператор по корню попадает в очередь. Сохранены URL names,
  login/no-store/logout-CSRF/BFCache. Ссылки сессии передают нужный семестр.
- Общая навигация: desktop sidebar, mobile пять нижних пунктов, профиль в
  шапке и запас под mobile nav. Сохранена палитра V1; у карточек честные empty
  states и видимая отметка конкурсного концепта. В README исправлены
  устаревшие описания и дан полный локальный путь с seed/Gunicorn.

## Ограничения

Проверки локальные на PostgreSQL/Chromium, DEBUG=False Gunicorn/WhiteNoise.
Не проверены публичный сайт, удалённый CI, физический телефон, доступность из
России, хостинг до даты итогов и production эксплуатация. Server/timer не
оставлен в качестве постоянного сервиса; публичного bind/туннеля нет. V2 и
разрешение публикации остаются за пользователем. Pytest выдаёт одно стороннее
предупреждение pytest-playwright о будущем изменении session fixture API;
тесты не пропускаются.
