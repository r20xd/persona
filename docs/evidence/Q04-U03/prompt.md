Найденные существенные проблемы submitting/retry сначала предложить минимальным контрактом.
6. Проверить контраст основных цветов/фокуса и readibility в рамках проектных ориентиров; не заявлять сертификацию WCAG/полный accessibility audit по нескольким assertions. Первый исполнитель успел восстановить Python3.13.14 через locked uv и загрузить engines; изменения приложения не делал. После рестарта daemon назначен единственный новый Sol/low `ui_accessibility_resume`. Own PG `deanery-q04-20261106` сохранён с label `deanery.qa=Q04-U03-20261106`, loopback55432; новый исполнитель подтвердил его состояние перед повторными действиями.

На host реально запускаются Chromium156 и Firefox157. WebKit27.2 скачан, но не запускается из-за отсутствующих runtime libraries. Родитель согласовал fallback: официальный Docker Playwright server `mcr.microsoft.com/playwright:v1.64.1-noble`, версия совпадает с uv.lock1.64.1, image после pull фиксируется digest. Документация: [Playwright Docker, remote connection](https://playwright.dev/python/docs/docker#remote-connection). Контейнер включает браузеры и runtime, а host Python3.13/pytest/Gunicorn сохраняются. Новые app API или production-контейнеры не добавляются.

Требования fallback: собственные unique name/label, только loopback WS port, user pwuser, init/private shm; без host mounts/repo/.env/.git/socket, host network, privileged/cap-add. Pytest подключается через BrowserType.connect, `expose_network='<loopback>'`, без `'*'`. Текущий установленный Python API принимает `endpoint` в connect_options, а не старое имя ws_endpoint (проверено в locked package source). Новый UI-модуль может иметь session connect_options fixture с явной loopback Q04_PLAYWRIGHT_ENDPOINT; остальные тесты без env работают локально. Установка host system packages не разрешена. Для воспроизводимости разрешён узкий QA helper в scripts; ownership/exact cleanup и безопасный env обязательны. Server может остаться только до независимого review родителя, затем exact cleanup.

Source audit родителя: активный login input наследует cursor:not-allowed и #6d7b6d на #edf0ea (расчёт контраста3.88:1). Проверить computed style и исправить через active-only accounts override, не менять disabled preview. Кандидаты keyboard audit: focus style не включает button/select/textarea, skip link и desktop nav имеют одинаковый z-index20; подтвердить достижимость браузером. В формах нужны понятная error summary и фокус; native POST/CSRF/submission_key/семантика статусов остаются.
