# COPY01 · Приёмка слогана боковой панели

**Статус** — `accepted`. 20 ноября 2026 года. PRD-03, PRD-04, F01. [Постановка](prompt.md) · [Реализация](implementation.md)

Независимый сценарий Chrome и PostgreSQL 17 прошёл с входом обеих ролей. Точный слоган помещается в боковой панели на 1440 × 900 и 851 × 768. При 360 × 780 видна нижняя навигация. Первичная проверка 851 × 650 показала ограничение высоты существующей панели студента. Сравнение в Chrome подтвердило, что замена текста не увеличивает нижнюю границу блока в этом режиме. [Снимок левой панели из тестового кабинета](sidebar-1440.png)

Проверены полный diff и `git diff --check`. В локальном кабинете HTML обеих ролей проверен в транзакции только для чтения. Воркер Gunicorn перечитал шаблон, readiness ответил HTTP 200.
