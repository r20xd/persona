# Контрольные случаи

Это критерии, а не результаты проверок.

- All доступно студентам и оператору; group/faculty — только подходящим студентам. Scope оператора на группу не даёт ему студенческие объявления.
- Публикация включается при publish_at<=now; истечение исключает expires_at<=now. Нет чужих counts или read markers.
- GET не пишет прочтение. POST с CSRF меняет только отметку текущего пользователя, повтор сохраняет исходное read_at.
- Notification-target разрешается заново по действующим правам: чужой request, отозванное зачисление или удалённая цель не раскрывают данные.
- Заявка/событие/Notification и перенос/история/Notification атомарны. Failure и stale version не оставляют частичный результат.
- Повтор ключа/версии не дублирует Notification, прочтение не сбрасывается при повторном создании.
- Upcoming только в ближайшие24h до срока; после срока только overdue. Пропущенный запуск догоняется без устаревшего upcoming.
- Связанный опубликованный результат подавляет напоминание только этого студента; будущая/неопубликованная оценка не подавляет. Нулевая опубликованная оценка тоже считается опубликованным результатом.
- Перенос увеличивает revision, отмена запрещает новые напоминания; повтор/параллельные команды не размножают записи.
- Старое уведомление остаётся историей, а ссылка показывает актуальные сведения и не утверждает, что студент точно не сдавал работу.
- Фиксация успешного запуска не происходит при ошибке; command имеет ненулевой exit code.
