## Регрессии и условия

- Серверный набор на PostgreSQL дал **481 passed**. В первом параллельном запуске 480 тестов прошли, а один тест доступа столкнулся с временным отсутствием CSS при пересборке общего `staticfiles` браузерной фикстурой. Повтор после завершения этой сборки прошёл целиком.
- **24 браузерных теста** прошли в Chrome. Набор включает 360/390/768/1440 px, клавиатуру, восстановление после потери ответа, повтор без дублирования заявки, смену аккаунта и каталог в конкурсной конфигурации. Существующая фикстура Playwright выдала предупреждение о будущих изменениях в pytest.
- В Firefox прошли **6 дополнительных браузерных тестов** на четырёх ширинах. Они подтверждают доступность полей и кнопок, клавиатурный фокус и повтор после потери ответа.
- Тестовая сборка WebKit 27.2 для macOS запустилась, но в двух попытках остановилась на открытии первой вкладки до запроса к приложению. Прогон WebKit остаётся открытым.
- Настоящая кнопка «Назад» в Chrome после смены студента вернула данные новой сессии. В этом прогоне Chrome сообщил `pageshow.persisted=false`, при возврате без смены сессии причиной исключения из BFCache указан `Cache-Control: no-store`. В наборе регрессий отдельно проверен обработчик синтетического `pageshow.persisted` при отключённой сети.
- Локальный кабинет на порту 8000 возвращает 200 для входа и readiness. В действующей локальной базе три активных вымышленных аккаунта с настроенными паролями и ожидаемыми ролями. У обоих студентов есть будущие занятия и сессия, у первого есть перенос. Проверка рабочей базы была только на чтение. Временные логины в браузерных тестах использовали пароли отдельного контура.
- Ruff, Django check, проверка миграций на отдельной PostgreSQL и `uv lock --check --offline` прошли.

Физический телефон, системный масштаб и опубликованный сайт остаются отдельными проверками. Подтверждение V2 даёт пользователь после просмотра.
