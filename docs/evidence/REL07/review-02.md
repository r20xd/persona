# REL07 · Повторное независимое ревью

**Статус** — `accepted` для навигационной части REV-08, PRD-02–04 и TECH-06. [Постановка](prompt.md) · [Реализация](implementation.md) · [Первое ревью](review.md)

На телефоне постоянно видны пять учебных разделов. «Учёба» открывает прежнюю страницу успеваемости. У оператора две ссылки, на очередь и уведомления. В широком кабинете используются прежние ссылки боковой панели. Дополнительные ссылки берутся из общего шаблона. Серверный флаг локального каталога применяется к обеим раскладкам, а в конкурсной конфигурации каталог отсутствует. Скрытая раскладка удаляется из порядка фокуса через CSS.

В Chrome 157 на PostgreSQL 17.11 основной агент проверил ширины 360, 390, 768, 850, 851, 1024 и 1440 px. На мобильных ширинах у студента пять равных ячеек одного ряда, подписи от 11 CSS px занимают одну строку и помещаются в свои ячейки. Размеры всех основных и дополнительных целей от 44 × 44 CSS px. Поле раскрытого меню совпадает с правым полем шапки. Проверены переход «Учёба» и `aria-current`, Tab, Enter, Escape, видимая рамка и возврат фокуса. Отдельный контекст с выключенным JavaScript открыл помощника и кота через нативное меню. С включёнными прогулками существующий наблюдатель скрыл кота при открытии «Ещё». После закрытия прогулки возобновились.

Снимки со специально созданными вымышленными данными просмотрены. В визуальном ревью применены критерии design-taste-frontend для читаемости, выравнивания, видимого фокуса и перекрытия целей. [Главная на 360 px](main-360.png) · [Меню на 360 px](more-360.png) · [Боковая панель на 1440 px](main-1440.png)

Серверные тесты `test_access_matrix.py`, `test_student_directory.py` и `test_cat_cameo.py` дали **164 passed**. В браузерном прогоне основного агента прошли **48 регрессий** каталога, чата, игры, полного пути до статуса справки, доступности форм, прогулок кота и учебных фильтров. Первые проверки дизайна потребовали исправлений, описанных в первом ревью. После исправлений все **7 сценариев** `test_design_browser.py` прошли у исполнителя. Основной повторил проверку раскладки, фокуса и меню, включая отдельный успешный прогон `test_mobile_more_native_and_keyboard`. В pytest было предупреждение от фикстуры pytest-playwright.

Ruff check, Ruff format, Django check, синтаксис двух JS-файлов и `git diff --check` прошли. Локальный Gunicorn перечитал приложение после `collectstatic`. Вход, оба health-пути и новые версии CSS и JS с хешами вернули 200.

Влияние карточки кота на форму помощника при закрытом меню относится к следующему блоку REV-08. Физический телефон и общий Taste gate сайта остаются отдельными проверками. Публичный релиз остаётся за V2.
